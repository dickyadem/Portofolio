06 / API map

Berkomunikasi
melalui REST.

Fake Store API menyediakan data demo yang cukup untuk mensimulasikan toko online.

Resource

  • POST /auth/login untuk token JWT.
  • GET /products dan kategori untuk katalog.
  • POST /carts untuk checkout.
  • GET /users dan operasi user untuk akun.

Payload checkout

{
  "userId": 1,
  "date": "2026-09-14",
  "products": [
    { "productId": 1, "quantity": 2 }
  ]
}

07 / Run locally

Jalankan
di mesin sendiri.

Butuh Node.js dan npm. Aplikasi memakai port development Create React App.

npm install
npm start

Buka http://localhost:3000 setelah server berjalan.

Build & test

npm test
npm run build

Build produksi dibuat ke folder build/.

08 / Known limits

Jujur tentang
batasan demo.

  • Write operation Fake Store API tidak persist di server.
  • Harga dari API berupa USD dan hanya diformat sebagai IDR tanpa konversi kurs.
  • Wishlist, live chat, loyalty, tautan legal, dan beberapa footer link masih placeholder.
  • Token login disimpan di localStorage browser.
  • Katalog dapat dibuka tanpa login, tetapi checkout membutuhkan token.
