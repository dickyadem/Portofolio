# Screenshot portofolio VideoBelajar

12 screenshot PNG halaman penuh dari aplikasi lokal, tanpa panel DevTools atau bingkai browser.

- Desktop: lebar 1440 px.
- Mobile: lebar 414 px (viewport 414 × 896).
- Gambar kelas, avatar, dan font dimuat dari sumber asli. Pemeriksaan otomatis tidak menemukan gambar rusak pada seluruh hasil.
- Nama peserta, invoice, pesanan, dan progres merupakan data demo khusus presentasi, bukan transaksi nyata. Tidak ada perubahan styling aplikasi khusus screenshot.

## Urutan presentasi

1. `01-desktop-beranda.png` — halaman utama.
2. `02-desktop-katalog.png` — pencarian dan katalog kelas.
3. `03-desktop-detail-kelas.png` — informasi dan kurikulum kelas.
4. `04-desktop-metode-pembayaran.png` — pilihan metode pembayaran.
5. `05-desktop-pesanan.png` — pesanan berhasil dan belum dibayar.
6. `06-desktop-kelas-saya.png` — kelas selesai dan sedang berjalan.
7. `07-desktop-belajar.png` — aturan dan daftar modul belajar.
8. `08-desktop-sertifikat.png` — pratinjau sertifikat peserta.
9. `09-mobile-beranda.png` — halaman utama responsif.
10. `10-mobile-katalog.png` — katalog mobile.
11. `11-mobile-belajar.png` — pembelajaran mobile.
12. `12-mobile-pesanan.png` — pengelolaan pesanan mobile.

Untuk portofolio ringkas, pilih 01, 03, 05, 06, 08, dan 09. Gunakan file PNG asli agar teks tetap tajam.

`capture.cjs` adalah script pengambilan; path Playwright di dalamnya khusus komputer ini. `capture-report.json` mencatat hasil pemeriksaan gambar. Seluruh folder ini diabaikan Git melalui aturan `/ss/`.
