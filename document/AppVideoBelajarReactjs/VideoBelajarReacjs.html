06 / Run locally

Jalankan
di mesin sendiri.

Gunakan Node.js 20.19+ atau 22.12+ dan npm sesuai versi Vite yang terpasang.

npm ci
npm run dev

Buka alamat yang ditampilkan Vite. Aplikasi tidak memerlukan konfigurasi .env.

Pengujian

npm test
npm run build

Build produksi menggunakan base path GitHub Pages dan HashRouter.

07 / Known limits

Jujur tentang
batasan demo.

  • Autentikasi, newsletter, pembayaran, dan data kelas masih berupa simulasi frontend tanpa backend.
  • Pemutar video belum memutar materi asli; progres video dicatat ketika pengguna berpindah lewat tombol berikutnya.
  • Login, progres, dan review memakai localStorage, sehingga belum tersinkron antarperangkat.
  • Sertifikat dibuat lokal sebagai SVG dan belum diterbitkan atau diverifikasi oleh server.
