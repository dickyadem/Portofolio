05 / Access model

Setiap role punya
batas yang jelas.

Level lebih tinggi otomatis memiliki akses level di bawahnya melalui pengecekan role bertingkat.

employee (1) → finance (2) → hr_staff (3) → manager (4) → admin (5)

Manager berfokus pada review dan approval, bukan input penggajian. Employee tidak memiliki akses manajemen untuk menghindari konflik kepentingan.

06 / Run locally

Jalankan
di mesin sendiri.

Backend API harus tersedia secara lokal atau gunakan endpoint production.

Install & configure

npm install

# optional .env
REACT_APP_API_URL=http://localhost:4000

Tanpa `.env`, aplikasi menggunakan fallback API production.

Start & build

npm start
npm run build
npm test

Buka http://localhost:3000 setelah server berjalan.

07 / Known limits

Catatan sebelum
dipakai produksi.

  • Frontend bergantung pada backend API terpisah untuk autentikasi dan seluruh data payroll.
  • Kredensial, kontrak API, dan deployment production harus dikelola di lingkungan backend yang aman.
  • Deploy GitHub Pages membutuhkan konfigurasi `homepage`, `BrowserRouter basename`, dan branch `gh-pages`.
  • Dokumentasi screenshot menggunakan data demo, bukan data karyawan atau transaksi nyata.
